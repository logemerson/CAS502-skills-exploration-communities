# Communication Plan

We will use GitHub Issues to track tasks and communicate about the project. Each feature will have its own issue. When one person completes work, they will comment on the relevant issue and tag the other person. We will aim to check GitHub at least once daily.

We will use Zoom sporadically to pair program and screenshare when the team sees fit. For urgent questions, we will use text messages, and we will use Slack DMs for less urgent matters related to the project.
