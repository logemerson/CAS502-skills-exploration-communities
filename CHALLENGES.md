# Project Challenges

## Technical Challenge
The Louvain algorithm may produce different numbers of communities depending on resolution parameters and the structure of the data. We will use default parameters initially and document the results we observe. If communities are too large or too small to be meaningful, we may need to adjust the resolution parameter.

## Process Challenge
Keeping scope limited. The temptation will be to add more features. We will stick to the defined basic functionality and only pursue nice-to-have features if core work is complete. We also anticipate the CAS 502 course will influence our implementation plan, perhaps re-assessing priorities after critical updates are completed.

## Teamwork Challenge
Coordinating work asynchronously with different schedules. We will use GitHub Issues to track who is working on what and ensure commits are small and well-documented. As mentioned in NetworkX challenges, the team has significant differences in experience, which increases the demand for strong team communication.
